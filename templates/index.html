About Demonstration Monitoring

Demonstration mode uses recorded Wi-Fi sensing data because physical ESP32 hardware is not connected.

To demonstrate the complete smart-home user experience, the system continuously replays 2,800 real held-out Wi-Fi CSI sensing windows through real pre-trained machine learning models (SVM, XGBoost, and Random Forest).

All occupancy predictions, security alerts, and event transitions reflect real model evaluations on held-out test data in real time.
